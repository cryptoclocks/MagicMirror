# Local MediaPipe assets

- Vision Tasks JavaScript/WASM runtime: `@mediapipe/tasks-vision@0.10.32`, Apache-2.0.
- `LICENSE` contains the upstream MediaPipe project license.
- `SOURCES.json` records original Google-hosted model URLs, byte lengths and SHA-256.
- Model files total about 9.8 MB; models and both SIMD/non-SIMD WASM runtimes total about 31 MB.
- Runtime code only requests these assets from the app's loopback server. There are no CDN imports.
- Background separation uses Selfie Segmenter; animation uses Face Landmarker and Pose Landmarker Lite.
- Avatar geometry and scenery are generated by this project's own code, not copied from Zoom.

Docs: https://developers.google.com/edge/mediapipe/solutions/vision/image_segmenter
https://developers.google.com/edge/mediapipe/solutions/vision/face_landmarker
https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker
